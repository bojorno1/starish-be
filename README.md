This was made as my Week 1 project for Half-Life, and is also my first project for Hack Club in general. 
This is my version of the project Starbie, found here: https://github.com/SharKingStudios/Starbie/
The project is a type of digital pet, controlled by two MX switches and uses a XIAO-ESP32-C3 as its main processor. The digital sprite is displayed via a 0.93" OLED display, in the center of the PCB. The pet is also controlled with a DHT11 environment sensor, and a MPU6050 accelerometer.
